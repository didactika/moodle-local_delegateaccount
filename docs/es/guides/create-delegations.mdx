Vaya a **Administración del sitio > Usuarios > Cuentas > Cuentas delegadas**. La pestaña **Usuarios autorizados** lista a todas las personas que tienen el permiso, con sus delegaciones activas y programadas. Busque por nombre, nombre de usuario, correo o número de identificación, y use los chips para ver a las personas que tienen delegaciones en un estado, o ninguna.

<Steps>
1. Seleccione **Crear delegaciones** en la parte superior de la página para elegir varios usuarios autorizados y varias cuentas a la vez, o el icono de añadir en la fila de un usuario para crear delegaciones solo para ese usuario.
2. Elija los **usuarios autorizados** y las **cuentas delegadas**.
3. Elija cuándo empieza el acceso y, opcionalmente, cuándo termina.
4. Cuando el sitio lo permita, elija si se notifica a las personas implicadas, y guarde.
</Steps>

Crear delegaciones para varias personas y varias cuentas crea todos los pares. Un par que ya tiene una delegación vigente se deja como está, de modo que repetir la acción es seguro.

## Qué ofrece el selector de cuentas

El selector de cuentas solo ofrece cuentas activas. Deja fuera:

- al propio usuario autorizado;
- las cuentas para las que ya tiene una delegación que no se ha revocado;
- la cuenta de invitado;
- los administradores del sitio, mientras estén protegidos.

Para dar acceso de nuevo cuando una delegación caduca, edite la delegación caducada en lugar de crear una nueva.
