Este es el camino más corto desde el plugin instalado hasta una persona que usa una cuenta delegada. Cada paso enlaza con la guía que profundiza en él.

<Steps>
1. **Instale el plugin y dé permiso a las personas.** [Instálelo](page:getting-started/installation), luego [cree el rol](page:getting-started/give-permission) que tiene `local/delegateaccount:use` y asígnelo a quienes vayan a usar delegaciones.

2. **Abra la página de gestión.** Vaya a **Administración del sitio > Usuarios > Cuentas > Cuentas delegadas**. La pestaña **Usuarios autorizados** lista a todos los que tienen el permiso.

3. **Cree la delegación.** Seleccione **Crear delegaciones**, elija el usuario autorizado y la cuenta, y fije cuándo empieza el acceso y, si lo desea, cuándo termina.

   <Screenshot src="asset:create-dialog.webp" alt="El diálogo para crear delegaciones" caption="Quién puede abrir qué cuentas, y durante cuánto tiempo." />

4. **La persona abre la cuenta.** Encuentra **Cuentas delegadas** en su menú de usuario y elige la cuenta. [Cómo lo hace](page:guides/use-a-delegated-account).

5. **Revise lo ocurrido.** Cada evento queda registrado con ambos nombres. Abra [el informe de actividad](page:guides/activity-report) de la delegación para verlo.
</Steps>

> [!TIP]
> Deje vacía la fecha de fin solo para un acceso que no tenga un final natural. Una fecha es la forma más sencilla de asegurarse de que una delegación no se queda abierta por descuido.
