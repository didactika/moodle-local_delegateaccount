This is the shortest path from the plugin installed to a person using a delegated account. Each step links to the guide that goes deeper.

<Steps>
1. **Install the plugin and give people permission.** [Install it](page:getting-started/installation), then [create the role](page:getting-started/give-permission) that holds `local/delegateaccount:use` and assign it to the people who will use delegations.

2. **Open the management page.** Go to **Site administration > Users > Accounts > Delegated accounts**. The **Authorised users** tab lists everyone who holds the permission.

3. **Create the delegation.** Select **Create delegations**, choose the authorised user and the account, set when access starts and, if you want, when it ends.

   <Screenshot src="asset:create-dialog.webp" alt="The dialog to create delegations" caption="Who may open which accounts, and for how long." />

4. **The person opens the account.** They find **Delegated accounts** in their user menu and choose the account. [How they do it](page:guides/use-a-delegated-account).

5. **Review what happened.** Every event is recorded under both names. Open [the activity report](page:guides/activity-report) of the delegation to see it.
</Steps>

> [!TIP]
> Leave the end date empty only for access that has no natural end. A date is the easiest way to be sure a delegation does not stay open by accident.
